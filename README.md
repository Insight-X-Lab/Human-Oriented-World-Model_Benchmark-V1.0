# 人本世界模型(Human-Oriented-World-Model) Benchmark v1.0
## 摘要

随着人工智能从信息处理工具逐步发展为能够持续感知、理解并参与真实人类活动的智能系统，模型能力评价也需要从传统的知识问答、语言生成和客观世界理解，进一步扩展至对“人”的感知、表征与理解。

人本世界模型（Human-Centered World Model）关注人与环境、事件及他人之间的动态关系，要求模型不仅能够识别客观事实，还能够感知人物状态，围绕人物形成结构化表征，理解其认知态度、行为表现、关系背景、现实需求及可能变化，并在有限信息条件下保持合理的证据边界与判断不确定性。

人本世界模型 Benchmark v1.0 是面向上述能力建立的基础评测体系。当前版本包含三个相互关联但独立计分的评测轨道：

*   **对话人物理解评测：** 通过教育、公安、纪委和司法四类行业谈话，评价模型对人物事实、状态、关系、需求和风险保护因素的理解与推理能力。

*   **视觉情绪感知评测：** 通过不同业务视角下的人脸图像，评价模型识别基础情绪类别及量化 PAD 情绪维度的能力。 

*   **人物档案画像评测：** 通过人物档案信息，形成结构化的人物画像并识别状态变化与支持需求的能力。


v1.0 包含 3021 条中文行业谈话样本、33,987 张基础情绪识别图像、761 条 PAD 情绪评测样本和300份学生档案。由于不同数据对应的输入形式、任务目标和评价指标不同，各类样本不进行简单数量合并，而是分别形成独立测试子集。

Benchmark 的评测重点不在于生成文本与参考答案的字面相似程度，也不限定模型必须采用某一种特征提取或推理方法，而在于最终系统是否能够准确感知人物状态、整合人物信息、形成有依据的结构化理解，并区分事实、合理推断和当前无法确认的内容。

因此，v1.0 可视为完整人本世界模型评测体系中的**人物理解与推理基础评测集**。其核心目标是回答：

> 当人工智能获得一段关于人的复杂信息后，是否能够从“理解情绪、语言和事件”进一步发展为“形成有证据约束的人物模型”。

# 1. Benchmark 定位

传统大模型评测主要围绕知识掌握、语言理解、逻辑推理、数学、代码和通用任务完成能力展开。这类评测能够衡量模型对信息和客观世界的处理能力，但不足以完整反映人工智能在真实人机交互场景中对人的理解水平。

人与客观对象存在显著差异。人的状态会随时间和情境变化，同一行为在不同关系、环境和事件背景下可能具有完全不同的意义；同时，人的情绪、态度、需求和行为动机通常不会直接以明确标签呈现，而是分散在语言、行为、关系和历史信息中。

因此，人本世界模型需要建立以人物为中心的信息组织与推理机制。其基本过程并非简单地从输入直接生成结论，而是逐步完成：

**信息理解 → 人物事实提取 → 人物状态与特征表征 → 事件和关系关联 → 需求与动机推理 → 不确定性判断 → 场景化理解与应用。**

人本世界模型 Benchmark 即围绕这一过程评价模型能力。基于这一能力链路，v1.0 通过三类任务形成递进的人物心理画像能力：

*   视觉情绪感知主要评价模型能否从图像中获得基础人物状态信息；
    
*   对话人物理解主要评价模型能否从多轮交互中理解人物事实、状态及其情境原因；
    
*   人物档案画像主要评价模型能否整合跨来源、跨时间的信息，形成相对稳定且可更新的人物表征。
    

需要特别说明的是，视觉情绪结果仅代表图像条件下的状态估计，不能单独用于推断人物动机、人格、欺骗、心理疾病或违法风险；人物画像和人物分析报告也只是标准化输出形式，Benchmark 真正评价的是生成结果背后体现的信息感知、人物表征、整合推理和证据约束能力。

# 2. 评测能力框架

人本世界模型需要从原始观察信息逐步形成对人物的结构化理解。结合当前文本数据条件，v1.0 重点评价以下五类核心能力。

| 能力维度 | 核心问题 | 主要评价内容 |
| --- | --- | --- |
| 人物事实理解 | 发生了什么 | 是否正确识别人物、情绪状态、事件、经历、观点、时间关系及明确陈述 |
| 人物表征与整合 | 这是一个怎样的当前人物状态 | 是否能够跨轮次整合状态、态度、沟通和行为信息，而非孤立摘录 |
| 情境与关系理解 | 为什么会呈现当前状态 | 是否能够识别重要事件、人际关系、家庭、学习工作及社会支持等背景 |
| 高层人物推理 | 人物当前在关注什么、需要什么 | 是否能够基于已有证据分析需求、动机、风险因素和保护因素 |
| 证据与不确定性 | 当前信息能够支持多强的判断 | 是否能够区分事实与推断，避免无依据补充和过度确定性结论 |

上述能力构成从“信息理解”向“人物理解”的递进链路。

其中，事实理解是后续分析的基础。如果模型错误识别人物情绪状态、人物经历、关系或事件，即使后续生成内容逻辑完整，也不能视为有效的人物理解。

人物表征强调模型能否将分散在多轮对话中的信息组织为以人物为中心的结构，而不是简单汇总谈话内容。例如，同一人物对不同事件的态度、持续出现的表达方式以及状态变化，应当被整合为相对一致的人物理解。

情境与关系理解进一步要求模型认识到人物状态并非孤立存在。家庭变化、学习或工作压力、重要关系、关键事件和社会支持，都可能共同影响当前表现，因此模型需要建立“人物—事件—关系—环境”之间的关联。

在此基础上，模型可以进一步进行有限的需求、动机和风险推理。但高层分析必须受到证据约束。人本世界模型的能力不仅体现在“能够得出结论”，同样体现在“知道什么时候不能得出结论”。对于证据不足、信息矛盾或者只能形成倾向性判断的内容，模型需要主动降低判断强度。

# 3. 数据集设计

## 3.1 数据构成

### 3.1.1 对话人物理解子集

Benchmark v1.0 共包含 400 条行业谈话样本，覆盖教育、公安、纪委和司法四个子集，每个子集 100 条。

| 行业 | 样本量 | 典型场景 | 主要人物理解内容 |
| --- | --- | --- | --- |
| 教育 | 100 | 学生访谈、心理关怀、师生沟通、家校沟通 | 情绪与心理状态、学习生活事件、人际关系、家庭支持、风险与保护因素 |
| 公安、纪委 | 2821 | 询问、走访、风险排查、监督谈话、线索核查、审查调查辅助谈话 | 人物背景、事件陈述、沟通特点、态度、行为倾向及待核实信息 |
| 司法 | 100 | 社区矫正、监所谈话、谈话帮教 | 规则认知、适应状态、家庭就业、社会支持、现实困难及支持需求 |

四个行业共享统一的人物理解能力框架，但在具体任务目标和信息关注重点上存在差异。这一设计用于同时评价两类能力：一是模型是否具备跨场景通用的人物理解能力；二是模型能否根据任务情境调整信息权重和分析重点，而不是使用同一套固定模板处理所有人物。

### 3.1.2 视觉情绪感知子集

视觉情绪感知子集包含基础情绪分类和 PAD 连续维度估计两项任务。

| 子任务 | 样本量 | 输入 | 输出 | 主要评价目标 |
| --- | --- | --- | --- | --- |
| 基础情绪分类 | 33,987张 | 高位监控、平视及其他业务场景下的人脸图像 | 预设基础情绪类别 | 评价不同视角、清晰度和业务环境下的情绪分类能力 |
| PAD情绪估计 | 761条 | 经质量控制的人脸图像 | Pleasure、Arousal、Dominance连续值 | 评价模型对连续情绪状态的量化能力 |

### 3.1.3 学生档案画像子集

学生档案画像子集包含300份经脱敏处理的学生档案。每份档案可包含基本信息、阶段记录、访谈内容、学习生活事件、人际关系、家庭支持、教师观察及其他经过授权的记录。模型需要整合不同来源和不同时间的信息，生成结构化学生画像，重点评价：

*   是否准确提取档案中的明确事实；
    
*   是否能够识别长期特征、近期状态和阶段性变化；
    
*   是否能够关联学习、情绪、家庭、人际和重要事件；
    
*   是否能够识别现实困难、支持需求、风险因素和保护因素；
    
*   是否能够区分历史信息、当前状态和待核实内容；
    
*   是否避免基于有限档案形成临床诊断、人格定性或标签化结论。
    

学生画像是基于当前档案形成的阶段性理解，应能够随着新记录加入而更新，而不是对学生形成固定不变的评价。

## 3.2 样本难度

三类子集分别覆盖不同形式的任务难度。

视觉情绪数据覆盖不同拍摄视角、距离、图像质量、遮挡情况和业务环境，用于评价模型在理想条件与真实场景之间的性能差异。

对话数据同时包含事实明确、信息跨轮分散、表达模糊、前后差异、证据不足及人物整体状态正常的样本，用于评价人物理解和不确定性处理能力。

学生档案数据覆盖记录数量不同、时间跨度不同、信息来源不同、部分字段缺失以及不同来源信息存在差异的情况，用于评价模型的长期信息整合能力和对缺失、冲突信息的处理能力。

## 3.3 数据划分与信息泄漏控制

训练集、验证集和测试集应按照人物身份及原始数据来源进行隔离，而不能只随机拆分单条记录。对话数据中，同一事件、同一人物或由同一原始材料改写产生的样本不得跨集合分布。正式测试集的人工标签、参考报告、关键点和证据标注应保持隐藏，防止模型通过检索、训练或提示构建间接获得参考答案。

# 4. 任务定义与数据格式

## 4.1 对话人物理解任务

模型输入为一段完整的行业谈话文本。文本按照对话轮次组织，并明确区分不同说话人。

部分任务可以同时提供必要的场景信息，例如谈话类型、人物角色或任务背景，但不会向模型提供人工参考报告或人工分析结论。

示例：

```text
[谈话场景] 学生关怀访谈

[老师] 最近上课感觉怎么样？

[学生] 有点跟不上，也不太想跟同学说话……

[老师] 这种情况大概持续多久了？

[学生] 两三个星期，家里最近也有一些事情。

```

模型需要基于完整谈话生成一份人物分析结果。不同模型允许采用不同的自然语言表述，但输出内容应能够覆盖以下基本信息：

1.  **人物概况。** 概括人物当前处境、主要事件和本次谈话的核心议题。
    
2.  **当前状态与核心特征。** 综合人物在谈话中的情绪、压力、适应情况、认知态度、沟通方式和行为表现。
    
3.  **关键事件与关系。** 识别对当前人物状态具有重要影响的生活事件、人际关系、家庭关系、学习工作环境及社会支持。
    
4.  **需求与可能动机。** 在现有证据基础上分析人物当前关注重点、现实困难、潜在需求及可能的行为动机。
    
5.  **风险因素与保护因素。** 根据具体行业任务识别需要进一步关注的因素以及能够提供支持的积极资源。
    
6.  **阶段性人物理解。** 在综合已有信息后形成与当前证据强度相匹配的阶段性结论，并明确尚无法确认或需要进一步核实的内容。
    

模型不得修改原始谈话事实，也不得补充输入中不存在的人物经历、事件或可识别个人信息。

## 4.2 视觉情绪感知任务

基础情绪分类任务输入单张人脸图像特征，输出规定标签空间内的一个情绪类别；PAD任务输入单张人脸图像特征，输出P、A、D三个连续数值。

推荐输出格式：

```plaintext
{
  "id": "emotion_000001",
  "emotion_label": "积极",
  "confidence": 0.82
}
```
```plaintext
{
  "id": "pad_000001",
  "pleasure": 1.25,
  "arousal": -0.40,
  "dominance": 0.75
}
```

置信度可以作为可选字段，但不得替代实际分类或回归结果。

## 4.3 学生档案画像任务

输入为一名学生经过脱敏处理的多来源档案记录。每条记录应尽可能包含记录类型、发生时间、信息来源和记录内容。

模型输出应覆盖：

1.  基本情况与档案范围；
    
2.  当前重点关注内容；
    
3.  情绪、压力与适应状态；
    
4.  学习与认知表现；
    
5.  重要事件及状态变化；
    
6.  人际关系与家庭支持；
    
7.  风险因素、保护因素与现实需求；
    
8.  阶段性结论及待补充信息。
    

所有结论应能够追溯至具体档案记录。模型不得将历史状态直接视为当前状态，也不得把记录缺失解释为不存在相关问题。

# 5. 行业场景适配

人本世界模型需要具有通用人物理解能力，但不同任务对人物信息的关注重点并不完全相同。因此，Benchmark 不要求模型在四个行业中生成完全相同的报告结构，而是要求模型在保持事实与证据一致的前提下，根据任务目标进行合理的信息选择和表达。

在**教育场景**中，重点关注学生当前情绪和适应状态、学习生活事件、人际关系、家庭支持以及风险与保护因素。模型输出用于帮助教师或相关专业人员更全面了解学生状态，不应将有限谈话信息直接转化为临床心理诊断。

在**公安场景**中，重点关注人物背景、事件相关陈述、互动和沟通方式、态度与行为表现，以及存在差异或需要进一步核实的信息。紧张、回避或表述不一致只能作为需要结合更多信息理解的现象，不能被模型直接认定为虚假陈述。

在**纪委场景**中，重点考察人物对不同议题的态度变化、配合情况、敏感内容反应、关注重点、可能的行为动机及心理状态。模型可以描述具有一定证据支持的倾向性表现，但不能将语言或行为表现直接转化为违纪事实判断。

在**司法场景**中，重点关注人物规则认知、矫正和适应状态、家庭及就业情况、社会支持、现实困难与服务需求。模型输出主要用于辅助人物理解和后续帮教支持，不用于形成确定性再犯预测或人格危险性结论。

通过上述场景设置，Benchmark 进一步评价模型能否实现从**通用人物理解能力**向**场景化人物理解能力**的迁移。

# 6. 评测方法

## 6.1 对话人物理解评分

人物分析属于开放式生成任务，同一段谈话可能存在多种合理表达方式。因此，Benchmark 不将 BLEU、ROUGE 等基于字面重合度的指标作为主要评价依据，而是重点评估生成结果与原始信息、参考人物理解和行业任务之间的语义一致性。

v1.0 设置五项一级评价指标。

| 评测维度 | 权重 | 评价重点 |
| --- | --- | --- |
| 人物理解准确性 | 30% | 人物、事件、关系、状态等核心信息是否与原始谈话一致 |
| 证据一致性 | 25% | 主要分析是否具有原始谈话依据，是否存在无依据补充或过度推断 |
| 人物表征完整性 | 20% | 是否完整覆盖当前场景中应关注的人物状态、特征、关系、需求等核心内容 |
| 场景适配性 | 15% | 是否根据不同行业任务合理调整分析重点、语言和结论方式 |
| 判断边界与安全性 | 10% | 是否将有限证据转化为诊断、欺骗、有罪、违纪或必然再犯等不当确定性结论 |

每条样本分别获得五项能力评分，并按照权重形成 0–100 分的综合成绩。四个行业分别计算独立子集成绩，最终 Overall Score 采用四个子集成绩的算术平均值，以避免单一行业样本数量或任务特征对总成绩造成过度影响。

正式榜单除展示综合成绩外，还应同步公布五项能力分数。这样能够进一步区分不同模型的能力结构，例如识别“事实提取准确但人物推理能力不足”“分析内容丰富但容易产生无依据推断”或“通用表现较好但行业适配能力较弱”等不同模型特征。

评分过程采用程序检查、语义评分与人工复核相结合的方式。程序规则主要检查输出格式、必需字段、样本完整性等确定性问题；内容准确性、证据一致性、人物表征及场景合理性采用经过人工样本校准的语义评分方法；对于临界成绩、异常高分、严重事实错误及安全边界违规样本，应进一步进行人工复核。

## 6.2 视觉情绪感知评分

基础情绪分类以 **Macro-F1** 作为主要指标，同时报告Accuracy、各类别Precision、Recall和F1。类别分布不均衡时，不应只使用Accuracy作为结论。

PAD连续维度估计分别报告P、A、D三个维度的：

*   一致性相关系数（CCC）；
    
*   平均绝对误差（MAE）；
    
*   均方根误差（RMSE）；
    
*   Pearson相关系数。
    

CCC主要衡量预测结果与人工标注在相关性和数值一致性上的综合表现；Pearson相关较高但MAE较大时，不能认定模型已经实现准确估计。两项任务应分别报告总成绩及不同视角、场景和图像质量条件下的分组成绩。

## 6.3 学生档案画像评分

| 评测维度 | 权重 | 评价重点 |
| --- | --- | --- |
| 档案事实准确性 | 30% | 人物、时间、事件和关系是否与原始档案一致 |
| 证据一致性 | 25% | 主要分析是否具有原始档案材料依据，是否存在无依据补充或过度推断 |
| 人物画像完整性 | 20% | 是否覆盖状态、学习、人际、家庭、事件、需求及支持资源 |
| 场景价值与可用性 | 15% | 是否形成清晰、可理解且具有支持价值的阶段性画像 |
| 证据边界与安全性 | 10% | 是否避免诊断化、标签化及无依据的确定性判断 |

评分采用确定性程序检查、语义评分和人工复核相结合的方式。事实错误、时间混淆、来源混淆、无依据补充和高风险定性应设置独立扣分项。

# 7. 参评规范与使用边界

参评模型应对全部测试样本独立生成结果，不得遗漏、重复或修改样本编号，不得针对测试样本逐条进行人工修改，也不得使用测试集参考报告及其派生标签进行训练、检索或提示构建。

提交结果应同时说明模型名称、版本、推理日期，以及是否使用提示工程、检索增强生成、领域本体、Agent、外部工具或多模型协同流程。Benchmark 不限制参评系统必须使用单一模型，其目标是评价最终人本理解系统的实际能力，但所有额外技术组件均应公开说明，以保证评测结果具有可解释性和可复现性。

人物分析结果本质上是模型基于有限信息形成的**阶段性人物理解**，不能视为对真实人物的完整评价。

因此，Benchmark 及其评测结果不得直接用于真实个体的自动化定罪、处罚、临床诊断或其他高风险决策。涉及未成年人和其他敏感人群的数据，应采用更严格的数据脱敏、访问控制和结果使用机制；不得利用事件、地点和关系等组合信息尝试重新识别数据主体。

对于人格、心理疾病、欺骗、违法违纪或再犯等需要更高证据标准的判断，模型应主动控制结论强度。现实应用中仍应保留人工复核、补充信息、进一步访谈以及纠错机制。

# 8. 版本演进

人本世界模型 Benchmark v1.0 初步覆盖静态视觉情绪感知、单次行业谈话理解和多来源学生档案整合，但仍不等于完整的人本世界模型评测。

当前视觉任务主要基于静态图像，尚不能完整评价语音语调、停顿、连续面部变化、人体动作、生理信号及人物与环境之间的动态互动。学生档案虽然包含一定时间信息，但仍以离线记录整合为主，尚不能充分评价模型在持续观察中的记忆更新、个体基线建立和状态演化预测能力。

| 阶段 | 主要评测目标 |
| --- | --- |
| v1.x | 扩充三类基础数据，完善类别、场景、人群及证据标注体系 |
| v2.x | 引入视频、语音、动作等多模态信息，评价跨模态状态感知与信息对齐 |
| v3.x | 引入连续观察和长期记录，评价个体基线、状态变化、记忆更新和趋势理解 |
| 后续版本 | 评价人物与环境、事件和他人之间的动态关系，以及不同条件下的人物状态演化和交互结果 |
